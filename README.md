# 🚀 LifeOS

> **LifeOS – Your Offline-First Intelligent Productivity Operating System**

LifeOS is a modern offline-first productivity application built with Flutter.

Unlike traditional to-do apps, LifeOS intelligently manages recurring tasks, habits, schedules, analytics, reports, and productivity insights while keeping all user data stored locally for maximum privacy.

---

## 📅 Smart Task Management

- Daily recurring tasks

- Custom recurring rules
- One-time tasks
- Date-range tasks
- Task dependencies
- Task templates
